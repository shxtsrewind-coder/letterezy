# Letterezy

A daily letter-bag word game for [bgameworld.com](https://bgameworld.com), alongside the Wordezy games, Mergezy, Sortezy and When & Where.

Each day's bag holds 25 letters, the same for every player, in a fixed order. Nine are on the rack at a time. Spell a word of 3–7 letters from them (tap or type), and the rack refills from the bag. Use every letter if you can: whatever's left when you finish counts against you.

- **Scoring**: each letter scores its Scrabble points. The 4th letter scores double, and a word that reaches the 5th square doubles. A 7-letter word adds +20. Leftover letters subtract their points; using all 25 adds +25.
- **Daily**: free. One hint a day (it fills in a good word from your rack). The day's three-star target is what a greedy solver scores with everyday words, so it's beatable with planning. A reload keeps your words. Results share spoiler-free: one row of squares per word, never the words.
- **Free play**: a fresh bag whenever you like, three hints a game. Behind a one-time $2 unlock, which is a stub until payments are set up (same as the other games).
- **Leaderboard and crowd stats**: same Supabase project and account system as the other games. Ranked by score; only a player's first finish each day counts.
- **Achievements, streaks**: stored on the device.

Every daily bag is drawn from the Scrabble tile mix with balanced vowels, at most two awkward letters (J K Q X Z), no Q without a U, and no long run of consonants, and the solver must be able to use nearly every letter before the bag is accepted.

## Word lists

`src/data/words.ts` is generated by `scripts/build_words.py` from public GitHub sources:

- [ENABLE](https://github.com/dolph/dictionary) (public domain): every 3–7 letter word is accepted.
- dolph/dictionary `popular.txt` and [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) OpenSubtitles ranks: the everyday words used for hints and the daily target, with rude or grim words removed.

## Run it locally

```bash
npm install
cp .env.example .env.local   # same Supabase URL and anon key as the other games
npm run dev
```

## Database

The leaderboard needs `supabase/migrations/20261011_letterezy.sql`. Run it once in the Supabase SQL editor for the shared project. It only creates new `letterezy_*` objects and is safe to run twice. Until it's run, the game still works and the leaderboard and crowd stats stay hidden.

## Deploy (Cloudflare)

Same setup as the other games:

1. Push this repo to GitHub.
2. In Cloudflare, create a Worker from the repo. Build command `npm run build`, deploy command `npx wrangler deploy` (see `wrangler.jsonc`).
3. Add the `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` build variables.
4. Add the custom domain `letterezy.bgameworld.com`.
5. In Google Search Console, submit `https://letterezy.bgameworld.com/sitemap.xml`.

## SEO

`index.html` has the title and description, canonical URL, Open Graph and X/Twitter cards with `public/og-image.jpg`, `VideoGame` structured data, a `<noscript>` description, icons and a web manifest. `public/robots.txt` and `public/sitemap.xml` point at the subdomain.

## Tuning

`src/lib/letters.ts` holds the rules: bag size, rack size, the bonus squares, bonuses, hints, and `makeBag` (the daily bag rules). Changing `makeBag` or the word lists changes every future daily bag, so avoid it mid-day once the game is live. `LAUNCH_DATE` is the day that counts as No. 1.
